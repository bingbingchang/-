# 近代史｜视频选题与史料工作台

> 这是一个**历史视频创作**仓库，不是要写一部百科全书。先弄懂历史，再讲好人物的故事；重要论断必须能找到出处。

## 当前专题

**[彭德怀的几件小事（1953—1959）](专题/彭德怀的几件小事/README.md)** — 视频项目《赫鲁晓夫开大会批判斯大林，坏透了！》。以1956年苏共二十大及1959年刘少奇讲话作反串引子，按时间讲文工团电报、军人誓词、农业浮夸、平江纸条与庐山信；已存完整口播初稿与1953—1962年文工团专档。


**[湖南农民运动（1923—1927）](专题/湖南农民运动/README.md)**

**[彭德怀的几件小事（1953—1959）](专题/彭德怀的几件小事/README.md)** — 新增故事素材库：从反对唱《东方红》、万岁口号、调选文工团员与修房子等旧事出发，整理11个候选故事，准备选取4—5件制作轻松、人物驱动的历史视频。

研究顺序：
1. **湖南农运的发展史**：从早期组织、北伐前后扩张到农会改变乡村生活与权力结构。这是当前第一优先级。
2. **进入毛泽东《湖南农民运动考察报告》**：文章要回应哪些争议？当时还有谁在说话？不能只引用毛泽东一方。
3. **沿着人物继续讲故事**：不同人的社会位置、利益和选择如何相互影响；可以拆成多期，不强求一集讲完。

不预设“农运一定过火”或“批评农运者一定正确”。暴力、制度与生产效果，应按具体证据讨论。四一二、马日事变是解读文章时展开的历史后续，不作为农运发展史的前提结论。

## 三个研究角色

| 角色 | 责任 | 最简交付 |
| --- | --- | --- |
| **A 史料研究** | 找当时的文献、报纸、当事人记录；核对日期与版本 | 带链接和注意事项的史料索引 |
| **B 人物与政治关系** | 研究人物主张、权力关系、利益冲突与态度变化 | 人物卡与关键关系线 |
| **C 故事编写与事实核查** | 决定详略、拆分视频；逐条核实关键事实与引语 | 可讲述的大纲、引文核对表 |

这是**工作分工**，不代表三个 Agent 已经自动在后台运行。

## 证据标记（用于所有资料）

- **【原件待查】**：已经定位到文献名称或后出全文，尚未见1926—1927年原版影印。
- **【同期文本】**：当时写成/发布的文章、决议、电报、报纸等；链接可能是后出整理本。
- **【事后回忆】**：亲历者多年以后回忆，必须与同期材料互证。
- **【后出研究】**：现代学术论文、党史文章和工具书，只用于线索与解释。
- **【待核】**：日期、数量、引语、版本、因果关系仍有争议。

**注意：文献是同期写成，不等于我们已拿到原始影印；作者在场或亲历，不等于其每项陈述均真实。**

本仓库主要保存**书目、来源链接、简短摘要与创作备忘**，不未经授权大段转载他人论文或扫描书刊。
