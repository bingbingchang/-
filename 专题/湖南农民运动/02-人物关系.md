# 02｜人物与关系：从人讲历史

不做百科人物传记。每位人物研究四件事：**当时处在什么位置？希望达到什么目标？面临哪些压力？他实际做过什么？**

## 第一圈：优先研究（与湖南农运和《考察报告》直接相关）

| 人物 | 叙事作用 | 优先问什么 | 主要来源 |
| --- | --- | --- | --- |
| **毛泽东** | 早期组织者、1927年湖南考察者和农运积极辩护者 | 他亲眼看到什么？哪些来自当地干部报告？为什么那时要写文章？ | 《中国佃农生活举例》《考察报告》、1927年2月给中央报告 |
| **易礼容** | 湖南省农民协会的实际组织人物 | 农会如何组织和运转、如何落实决议？ | 1926省农代会文件、湖南省档案局机构资料 |
| **李维汉** | 中共湖南区委负责人 | 湖南党组织怎样观察农运中的冲突？毛泽东调查前后判断如何变化？ | 1927年2月《湘区一月份农民运动情况》；《回忆与研究》 |
| **陈独秀** | 中共中央领导人 | 何时主张发动农运？何时强调联盟与土地政策的边界？其观点是否随局势变化？ | 1926年相关中央文件、1927年4月29日中共五大报告 |
| **瞿秋白** | 推动《考察报告》传播的支持者 | 为什么积极为毛泽东的文章写序？其土地政策主张是什么？ | 1927年4月11日《湖南农民革命》序 |
| **农会干部、佃农、乡村绅士/家属** | 让观众理解制度改变如何落在具体人身上 | 哪些姓名、行为、时间有当年文字记载？ | 大会文件、日记、报纸、地方案件记录；绝不为戏剧效果虚构证词 |

## 第二圈：解读文章或后续故事时再展开

| 人物 | 对故事的重要性 | 需要避免的简化 |
| --- | --- | --- |
| **邓演达** | 国民党内支持农运及土地改革的关键人物，帮助解释国民党内部的差异 | 国民党≠都反农运 |
| **唐生智** | 湖南军队和武汉政府军事政治关系中的重要实力人物 | 湖南冲突≠蒋介石单线遥控 |
| **何键** | 湖南军队与马日事变的重要关联人物 | 要核清其当时职务、上下级关系与实际行动 |
| **许克祥** | 马日事变的直接军事行动者；可提供冲突现场叙述 | 1956回忆录≠1927现场证据 |
| **蒋介石** | 国民党内部争权、北伐与四一二背景 | 不能说当时他控制一切，也不能说他毫无权势 |
| **汪精卫** | 武汉国民政府及其政策转向 | 武汉分共与上海四一二、长沙马日不同，需分开叙述 |
| **彭湃** | 广东海陆丰农运先行者；帮助交代全国农运方法与人员来源 | 不是湖南故事的主角，出现即可 |
| **彭述之** | 当时党内宣传与文章刊载争论相关人物 | 先求同期文件，再使用后出回忆解释刊发过程 |

## 可扩展但先不进入剧本

胡适、章太炎、地方开明士绅、国民党知识分子、普通军人家属。**只有找到1926—1927年有关湖南农运的确切同期文字，才安排他们“出场评论”。** 不因为人物有名就假定他有观点。

## 人物关系图（待考证的结构，不是因果结论）

- 湖南农会 ←→ 佃农/贫农与乡村地主、绅士：经济与基层政治权力的争夺；
- 湖南农会 ←→ 国民党湖南省党部/中共湖南区委：组织、保护与指导关系；
- 湖南农会 ←→ 湖南系军队及其家属：支持北伐、乡村利益碰撞、政治忠诚问题；
- 毛泽东 ↔ 李维汉 ↔ 陈独秀：地方调查、湖南报告与中共中央策略的沟通；
- 毛泽东 ↔ 瞿秋白 ↔ 邓演达：围绕农运、土地与文章传播的支持/合作线索；
- 唐生智—何键—许克祥：具体军队编制、职权和指令须按1927年文书重新核查，不凭后人概括直连命令关系。

## 人物卡写作模板（每人半页足够）

- 人物：姓名、1926—1927年当时职务（含任职时间）；
- 立场：以**发生日期+原话出处**记录，避免“始终”一类跨时段标签；
- 行动：对农会、军队、土地政策或出版具体做过什么；
- 关联：与谁合作/冲突，证据来源是什么；
- 镜头价值：一处确证场景或一段可靠文字；
- 待核：本人物最值得继续查的一件事。

真正可以推动故事的对象优先；涉及具体军官或家属姓名时，要从同期材料独立证实。
