# 湖南农民运动专题（1923—1927）

## 研究定位

**我们首先研究湖南农民运动的发展历史。** 要让观众理解它从哪里来、农民为什么组织、在北伐背景下怎样扩大、农会怎样改变乡村的权力和日常生活。

在这个历史基础上，才进入毛泽东的《湖南农民运动考察报告》。这篇文章是一个**叙事入口**，不是裁判书；读文章时引入当时共产党内部、国民党内部、军官、农民和士绅的其他视角。争论、军事分裂是沿人物故事展开的后续，**不是本专题开头硬套的三个问题**。

我们允许讲成多期，不要求所有人物一集讲完。之后若研究海陆丰或土地改革，另建专题；不要把别的历史阶段直接塞进湖南农运故事。

## 内容详略

| 详讲 | 略讲 | 暂不做 |
| --- | --- | --- |
| 农民生活中租佃、税捐、债务与乡村权力 | 国共合作的整个来龙去脉 | 全湖南逐县资料 |
| 1923的早期组织与1925—1927的扩张机制 | 北伐战争的完整军事战史 | 全国农运和土改通史 |
| 农会的组织、行动、权力变化及其具体例子 | 农会规模的小数点统计 | 考证所有地方干部 |
| 毛泽东报告写作背景、文本和当时的不同观点 | 所有党派章程与会议程序 | 预设因果的暴力/生产力结论 |
| 真正推动情节的几位人物 | 无关故事的完整履历 | 不做证据核对的精彩传说 |

## 三个角色怎样用

- **A 史料**：先搞明白来源及版本。只要找到一份能推动故事的同期材料，就交给B与C，不求搜罗穷尽。
- **B 人物**：追人物的“位置→选择→反应→变化”，连接组织和利益关系；不提前划定正派反派。
- **C 故事+核查**：做分集和叙事节奏，检查时间先后、引语原话、因果是否被夸大。

## 开工顺序

1. 先完成约6个时代节点的历史背景（目前是草稿）；
2. 从史料里挑 **2个农民或农会生活场景** 和 **2段当事人争论**；
3. 开始逐段读《考察报告》，每段旁边放另一人的同期材料；
4. 再决定分几期、每期讲什么，不因材料多而拖延制作。
