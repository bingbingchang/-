# 彭德怀的几件小事｜两期历史视频创作工作台

> 项目更新：2026-10-15。**不再只挑四五件；把十余件有价值的彭德怀故事都讲出来，分上下两期。** 不是严肃讲座；用朴实口语、具体人物和意料之外的后续发展串起历史，不预先给观众宣布价值判断。

## 暂定主标题（反串）

《赫鲁晓夫开大会批判斯大林，坏透了！》（上）／（下）

**开场共用一条悬念**：1956年赫鲁晓夫在苏共二十大秘密报告中批判斯大林；中国共产党讨论反个人崇拜与斯大林评价，刘少奇也参与讨论。1959年8月17日，刘少奇却在庐山后会议上批判彭德怀试图在中国反对个人崇拜，列举了一些彭的旧事。观众自然好奇：这些旧事到底是什么？

**叙事方法**：开场借1956和1959的政治反差引出彭德怀，随后回到1953年，按事情发生顺序讲。文工团是第一期的重点故事，交代1953筹建、萧华检讨、毛泽东批示、1954重新组团、1958撤销、1959重翻旧账的全过程。

## 两期安排

- **上集（1953—1957）**：文工团、侄女学费、北海公园清场、唱《东方红》争议、党章争议、军人誓词、各地修建接待住房（确切时间待查）。
- **下集（1958—1959）**：展览馆造假、夜里数禾蔸、敬老院、学生口粮、老红军纸条、后勤学院的“万岁”、庐山来信、集体领导争论、“斯大林晚年”话语的归属，结尾回到刘少奇8月17日讲话。

## 事实使用边界

- **刘少奇的讲话与黄克诚的批判发言不拼接为同一逐字引文**：修房子、调文工团员更明确见于黄克诚的发言；刘谈了《东方红》、喊万岁、党章、集体领导、自我批评等。
- **1956与1959的刘少奇分开**：1956中国官方文章既承认批评个人崇拜的价值，又不同意全盘否定斯大林，刘参加了有关讨论；1959他公开强调提高领袖威信。没有证据就不要把1959年的话说成1956年的原话。
- **文工团按完整事件链讲**：不能把“选妃”比喻当作性丑闻已被证实，不能说彭1953年一骂就永久解散文工团。
- **房子、军人誓词和“斯大林晚年”**有必要追问出处、场合和说话人；不编出彭在某栋楼现场叫停工程或“亲自宣布毛已进入斯大林晚年”的情节。
- **后出回忆要标身份和年代**，但不用每隔两句在口播中防御式提醒；出处放视频简介、字幕和仓库索引。

**原则**：让视频好看，让幕后核查扎实。查史料是为了敢把故事讲清楚，不是为了把影片写成文献综述。
