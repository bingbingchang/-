## 做片原则

- 旁白朴实，情节具体，可有幽默和反差，不作结尾说教，也不把人物写成一贯正确的圣人。
- 1959年刘、黄等不同人的转述不要混成“刘的完整原话”；引文有出处再使用。
- 1953年文工团遭反对**≠**1953年永久撤销；1958年撤销主要是军队精简，不能倒归因彭的1953批评。
- 1956年的中共公开表态与刘1959年的讲话分开叙述，不替任何人虚构当场反应。
- 影像来源与拍摄年代标明；复刻文电不是原件。
