# 彭德怀的几件小事｜历史视频故事工作台

> 状态：素材收集与选题阶段（2026-10-15）。**不是严肃历史讲座**。先让事件、人物和意外转折说话；最终只选最有故事性的四至五件事，不急着下政治结论。

## 起点

1959年8月17日，刘少奇在中央工作会议上谈到彭德怀反对个人崇拜，提及唱《东方红》、喊“万岁”、所谓“斯大林后期”、集体领导、自我批评、功劳归属等事。另据庐山会议上黄克诚的批判发言，彭德怀对各地修建接待毛泽东的房屋不满，也批评过从部队调选文工团员的方式。

**关键区分**：这不是一篇彭德怀的“自述”，而是1959年政治批判场景中刘少奇、黄克诚等人的转述和指控。把它当作寻找历史事件的线索，不把所有指控直接写成彭德怀亲口说过的话。

## 读什么

- [01-候选故事.md](01-候选故事.md)：11个候选故事，每个都有可拍场景、真实细节、证据分级和待核点。
- [02-史料与引文核查.md](02-史料与引文核查.md)：原始文稿、会议记录、当事人自述、后出研究；专门标注容易误传的地方。
- [03-视频构想.md](03-视频构想.md)：面向普通观众的节奏、冷开场、场景选择及旁白试写；提供四至五件事的首选组合。

## 创作约定

1. **故事先行**：从一张电报、一堵墙、一份粮食成绩表、一张纸条讲起，不按“反特权—反崇拜—反蛮干”三段式念提纲。
2. **可拍优先**：尽量找得到当年的文稿、场地、照片、当事人姓名；出处不足的桥段先挂起。
3. **不拼凑直接引语**：会议转述写“据某人后来记载/据当时批判发言”，不能变成亲历镜头的逐字对白。
4. **不是给彭德怀写圣人传**：不预设所有行为都正确；保留人物性格的矛盾与反转，例如1953年反对调选条件，并不等于始终反对成立文工团。
5. **不把后建房屋提前拍进1959年**：建筑要逐栋核实建成日期；“斯大林晚年”由谁先说，也不得直接归给彭德怀。

**工作逻辑**：先攒11件 → 查史料补足场面 → 用戏剧张力选4—5件 → 撰写脚本与素材分镜。
